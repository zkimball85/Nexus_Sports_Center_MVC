# Nexus Sports Center

Nexus Sports Center is a responsive web application built with ASP.NET Core MVC (.NET 10), Entity Framework Core, and Bootstrap 5. It provides sports league management capabilities, including team roster tracking, game scheduling, venue selection, and historical score logging.

---

## Author

- **Zac Kimball**

---

## Key Features

- **Team & Roster Management:** Create and update sports teams, assign home venues and sports, and manage detailed player rosters including jersey numbers and positions.
- **Game Scheduling & Venue Management:** Schedule matches between Home and Away teams at specific stadiums or school venues across different sports.
- **Score Logging:** Record final scores, match completion statuses, and game notes.
- **Score History & Analytics:** Search and filter historical game results by sport, team, venue, or date.
- **Responsive Navigation:** Clean web interface built with Bootstrap 5 dark theme for desktop and mobile devices.

---

## Tech Stack

- **Framework:** .NET 10.0 (ASP.NET Core MVC)
- **Database / ORM:** SQL Server LocalDB with Entity Framework Core 10
- **Frontend:** C# Razor Views (`.cshtml`), HTML5, CSS3, Bootstrap 5
- **IDE:** Visual Studio 2026 / Visual Studio Code
